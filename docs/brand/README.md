# Kpstn Studios brand

The studio's logo files, drawn on 2026-11-11 when MSG Studios became
**Kpstn Studios**. The full brand book (colours, type, voice and how to use the
logo) is the **Kpstn Studios** design system artifact on claude.ai; these are
its source files.

| File | Use it for |
| --- | --- |
| `kpstn-studios-mark.svg` | The mark: a stone peak with a marigold capstone set on top, on the night tile. Light grounds. |
| `kpstn-studios-mark-paper.svg` | The same on a paper tile, for dark grounds and photos. |
| `kpstn-studios-wordmark.svg`, `-paper.svg` | "kpstn studios" drawn from one round stroke (not a font), the i's dot marigold. |
| `kpstn-studios-lockup.svg`, `-paper.svg` | Mark and wordmark side by side: store pages, end cards, a site header. |
| `play-developer-icon-512.png` | Play Console → Developer page → icon (512 × 512). |
| `play-developer-header-4096x2304.png` | Play Console → Developer page → header image (4096 × 2304). |

Colours: night `#10202B`, paper `#F4F6F3`, marigold `#F4A300`, lagoon
`#0E6F6B`. Write the name **Kpstn Studios**. Keep a clear space of half the
mark's height around it; don't recolour, outline or stretch it. The mark reads
down to 20 px; below that, use the name in text.

Inside No Paddle the studio appears once, at the foot of Settings: the mark and
"Made by Kpstn Studios".

The MSG Studios files (an m as two hills under a sun) are in the git history
before 2026-11-11.
