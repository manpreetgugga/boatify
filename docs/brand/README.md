# MSG Studios brand

The studio's logo files, first drawn on 2026-10-31. The full brand
book (colours, type, voice and how to use the logo) is the **MSG Studios**
design system artifact on claude.ai; these are its source files.

| File | Use it for |
| --- | --- |
| `msg-studios-mark.svg` | The mark: two hills (an m) and a rising sun, on the night tile. Light grounds. |
| `msg-studios-mark-paper.svg` | The same on a paper tile, for dark grounds and photos. |
| `msg-studios-wordmark.svg`, `-paper.svg` | "msg studios" drawn from one round stroke (not a font), the i's dot marigold. |
| `msg-studios-lockup.svg`, `-paper.svg` | Mark and wordmark side by side: store pages, end cards, a site header. |
| `play-developer-icon-512.png` | Play Console → Developer page → icon (512 × 512). |
| `play-developer-header-4096x2304.png` | Play Console → Developer page → header image (4096 × 2304). |

Colours: night `#10202B`, paper `#F4F6F3`, marigold `#F4A300`, lagoon
`#0E6F6B`. Write the name **MSG Studios**. Keep a clear space of half the
mark's height around it; don't recolour, outline or stretch it.

Inside No Paddle the studio appears once, at the foot of Settings: the mark and
"Made by MSG Studios".
